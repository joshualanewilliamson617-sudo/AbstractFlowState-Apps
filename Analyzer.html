data_analyzer.py

      
The full script. Every tab in this app maps to one section: overview → describe(), groups → group_by(), compare → correlation_and_trend(), over time → time_series() and moving_average(), new columns → add_column().

      

    

  


  

    
How to use it

    
    
      
  1. Table: type, paste, or load data. Rows and columns grow as you need them.
    2. 
      
  2. Filter strip: pick the main column and a cutoff. Rows that fail are dropped from every tab.
    3. 
      
  3. Overview: every summary number for the main column, a box plot that flags outliers, a histogram and a percentile finder. Turn on "Show the math" to see each formula worked out.
    4. 
      
  4. Groups: totals and averages per category, like views per topic.
    5. 
      
  5. Compare: how two columns move together (correlation and trend line), and how they differ side by side.
    6. 
      
  6. Over time: pick a date column to see the trend, a moving average and growth per period.
    7. 
      
  7. Rhythm: type a step pattern, see it drawn as a Paint-style pixel line, and get a proven answer on whether it lands on your number. Save lines to stack them in 3D and compare every pair.
    8. 
      
  8. Python: one command that repeats all of it with the script.
