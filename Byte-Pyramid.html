BOTTOM RING • BASE 12

Each colored group of 4 squares is one base-12 digit (0–9, then A = 10, B = 11). Patterns worth 12–15 are not digits.

MIDDLE RING • ONE BYTE

HOW IT READS

  • Black square = 1, white = 0. Bit weights in each group of 4 are 8, 4, 2, 1.
  • Bottom: 12 bits = three base-12 digits, coded like BCD but stopping at B. No real hardware uses this; it is this game's own code.
  • Middle: 8 bits = one byte. ASCII only defines 0–127, so the first bit must be 0. EBCDIC (code page 037, IBM mainframes) puts its letters and digits up high, with the first bit 1.
  • So no byte is the same letter in both codes. In EBCDIC, A–I are C1–C9, J–R are D1–D9, S–Z are E2–E9.
